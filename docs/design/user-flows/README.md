# User Flows and Screen Navigation Index

The [screen flows](../ui-screen-flows.md) describe the web and Flutter routes at the LA-361 source baseline. This directory links the role design references. The [Confluence target](https://hungndemail.atlassian.net/wiki/pages/viewpage.action?pageId=11894809) was at v4 at review time and v5 is planned.

| Actor | Design reference | Implemented entry points |
| --- | --- | --- |
| Customer | [Customer flow](customer.md) | Web `/orders`, Flutter `/customer` |
| Dispatcher | [Dispatcher flow](dispatcher.md) | Web workspace `/` and `/dispatcher/approvals` |
| Station Operator | [Station operator flow](station-operator.md) | Web `/stations`, Flutter `/operator` |
| Logistics Manager | [Manager flow](logistics-manager.md) | Web `/manager/analytics` |
| System Administrator | [Administrator flow](system-administrator.md) | Web `/admin/users`, `/admin/roles` and `/admin/audit-logs` |
