# Test reports

- [Execution report](test-report.md): functional results and CI/local runs separated by source revision and environment.
- [Performance report](performance-report.md): original workload/thresholds, historical failures and later scoped reference validation.

These reports are execution ledgers, not a single latest global test count. Read the dated baseline of each row. More focused runtime records live under [acceptance](../acceptance/README.md); original artifacts live under [evidence](../evidence/README.md). See the [testing index](../README.md) for open acceptance boundaries.
